# EvoLink Nano Banana 2 (Official)

Google Nano Banana 2 / Pro / Lite 文生图、图生图、图片编辑。

- **model**：官方渠道（nano-banana-2 / pro / 2-lite）与 beta 渠道可选；提交时自动换算成 API 真实模型 ID
- **quality**：分辨率档位（0.5K~4K，随型号而异；Lite 固定 1K，选高了自动回退并提示）
- **图生图**：把「加载图像」连到 image1~image4 即可，本地图经 EvoLink 官方通道上传（72 小时自动删除）；含真人照片的参考图最多 4~5 张
- **thinking_level**：生成前推理深度（仅部分型号）；**web_search**：联网搜索优化（可能额外收费）

参数不变时重复运行走 ComfyUI 缓存，不重复扣费。
