# EvoLink Veo 3.1 (Official)

Google Veo 3.1 文生视频、首尾帧图生视频、参考图生视频，支持原生音频。

- **preview 版**（generate / fast-generate）：duration 4/6/8s、quality 到 4k、seed、negative_prompt、generate_audio（音频额外收费）
- **beta 版**（pro / fast）：参数精简、仅 720p
- **图生视频**：first_frame=首帧，再接 last_frame=首尾帧；REFERENCE 模式最多 3 张参考图，配合 generation_type 手动指定
- 生成通常需要几分钟，可随时取消等待
