# EvoLink Seedream 5.0 (Official)

字节豆包 Seedream 5.0 Pro / Lite / 4.5 / 4.0 文生图、图生图、图片编辑，中文提示词友好。

- **size**：auto / 比例（1:1、16:9、9:21 等）/ 像素（2048x2048）
- **quality**：各版本档位不同（5.0-pro 最高 2K 档、5.0-lite 为 2K/3K/4K），选了不支持的档自动回退
- **n**：一次多图（仅 lite/4.5/4.0，需同时在 prompt 里说明张数）
- **图生图**：接 image1~image4；5.0-pro 参考图上限 10 张，其余 14 张
