# EvoLink Seedream 5.0 (Official)

ByteDance Doubao Seedream 5.0 Pro / Lite / 4.5 / 4.0 text-to-image, image-to-image and editing. Excellent Chinese prompt support.

- **size**: auto / ratio (1:1, 16:9, 9:21…) / pixels (2048x2048)
- **quality**: tiers differ per version (5.0-pro tops at 2K tier, 5.0-lite offers 2K/3K/4K); unsupported picks fall back automatically
- **n**: multiple images per run (lite/4.5/4.0 only; also ask for the count in your prompt)
- **image-to-image**: connect image1–image4; ref limit 10 for 5.0-pro, 14 otherwise
