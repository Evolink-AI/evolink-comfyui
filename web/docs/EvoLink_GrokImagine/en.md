# EvoLink Grok Imagine Image 2.0 (Official)

xAI Grok Imagine Image 2.0 text-to-image, image-to-image and multi-image editing.

- **No image = text-to-image; 1-3 reference images = image editing**, no model switch needed
- In multi-image edits reference images as `<IMAGE_0>`, `<IMAGE_1>` in the prompt (0-based)
- **size**: 13 ratios + auto (auto usually leans portrait); **resolution**: 1K / 2K
- **quality**: low is faster & cheaper / medium for better quality (no high tier)
- **n**: up to 10 images per run, billed per image; the reference-image surcharge is per request, not multiplied by n
