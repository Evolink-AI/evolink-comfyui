# EvoLink Grok Imagine Image 2.0 (Official)

xAI Grok Imagine Image 2.0 文生图、图生图、多图编辑。

- **不接图=文生图；接 1~3 张图=图片编辑**，无需换模型
- 多图编辑在 prompt 里用 `<IMAGE_0>`、`<IMAGE_1>` 引用第 1、2 张参考图（从 0 开始计数）
- **size**：13 种画幅 + auto（auto 通常偏竖图）；**resolution**：1K / 2K
- **quality**：low 更快更便宜 / medium 质量更好（无 high 档）
- **n**：一次最多 10 张，每张独立计费；编辑时参考图按次加价、不随 n 翻倍
