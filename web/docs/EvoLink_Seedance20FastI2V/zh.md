# EvoLink Seedance 2.0 (Official)

字节豆包 Seedance 2.0 / 2.0 Fast 文生视频、图生视频。同步音频不额外收费。

- **模型选择决定模式**：*-text-to-video / *-image-to-video（接 first_frame，可再接 last_frame 做首尾帧）
- **duration**：4~15 秒任意整数
- **quality**：480p 低价档～4K（1080p/4k 仅 standard 档；fast 最高 720p，选高了自动回退）
- **aspect_ratio**：fast 图生视频固定 adaptive（跟随首帧图）
- 更长时长（最长 30 秒）与自动时长请用 Seedance 2.5 节点；更低成本用 Seedance 2.0 Mini 节点
