# EvoLink Image (All Models)

Dynamic image node: call every EvoLink image model (GPT Image 2, Nano Banana 2/Pro, Seedream 5.0, …) from one node.

- Only size is exposed as a widget; pass model-specific params (quality, n, mask_url, …) via **extra_params** as JSON, e.g. `{"quality": "2K", "n": 2}`
- See evolink.ai/docs for per-model parameters
