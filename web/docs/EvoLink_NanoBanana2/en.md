# EvoLink Nano Banana 2 (Official)

Google Nano Banana 2 / Pro / Lite text-to-image, image-to-image and image editing.

- **model**: official channel (nano-banana-2 / pro / 2-lite) or beta channel; friendly names are mapped to real API model IDs on submit
- **quality**: resolution tier (0.5K–4K depending on variant; Lite is fixed 1K — unsupported picks fall back automatically with a note)
- **image-to-image**: connect Load Image to image1–image4; local images are uploaded through EvoLink's official file channel (auto-deleted after 72h). Max 4–5 photos containing real people
- **thinking_level**: reasoning depth before generation (select variants); **web_search**: use web results (may incur extra cost)
