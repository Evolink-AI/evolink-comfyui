# EvoLink Z-Image Turbo (Official)

Alibaba Z-Image Turbo fast budget text-to-image.

Outputs: `image` (downloaded result), `task_id`, `status_info`, `result_urls` (raw links, one per line, 24h expiry), `response_json` (full task API response for downstream parsing).
