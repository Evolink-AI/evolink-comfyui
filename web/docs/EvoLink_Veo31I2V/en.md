# EvoLink Veo 3.1 (Official)

Google Veo 3.1 text-to-video, first/last-frame image-to-video and reference-to-video, with native audio.

- **preview** models: duration 4/6/8s, quality up to 4k, seed, negative_prompt, generate_audio (audio billed extra)
- **beta** models: minimal params, 720p only
- **image-to-video**: first_frame = first frame; add last_frame for first+last; REFERENCE mode takes up to 3 refs — set generation_type explicitly
