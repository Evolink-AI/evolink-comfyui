# EvoLink Seedance 2.5 (Official)

字节豆包 Seedance 2.5 / 2.0（standard / fast / mini）文生视频、图生视频。同步音频不额外收费。

- **模型选择决定模式**：*-text-to-video / *-image-to-video（接 first_frame，可再接 last_frame 做首尾帧）
- **duration**：2.5 支持 4~30 秒或 -1 自动时长；2.0 系 4~15 秒
- **quality**：480p 低价档～1080p；4k 仅 2.0 standard；fast/mini 最高 720p
- **aspect_ratio**：图生视频固定 adaptive（跟随首帧图）
- reference-to-video / video-edit / video-extend 请用「EvoLink Video (All Models)」节点 + extra_params
