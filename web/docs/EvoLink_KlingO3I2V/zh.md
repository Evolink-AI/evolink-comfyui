# EvoLink Kling 3.0 (Official)

快手可灵 Kling V3 / V3 Turbo / O3 文生视频、图生视频。

- **模型选择决定模式**：*-text-to-video 文生视频；*-image-to-video 图生视频（必接 first_frame）
- **duration**：3~15 秒任意整数；**quality**：720p/1080p/4k（Turbo 无 4k）
- **sound**：音效开关（Turbo 不支持）；**首尾帧**：first_frame + last_frame（Turbo 仅首帧）
- 图生视频画幅由首帧图决定（宽高≥300px，比例 1:2.5~2.5:1）
- 多分镜（multi_shot）等高级用法见 evolink.ai/docs
