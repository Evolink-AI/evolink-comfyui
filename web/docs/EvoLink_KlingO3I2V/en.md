# EvoLink Kling 3.0 (Official)

Kuaishou Kling V3 / V3 Turbo / O3 text-to-video & image-to-video.

- **Model choice sets the mode**: *-text-to-video vs *-image-to-video (first_frame required)
- **duration**: any integer 3–15 s; **quality**: 720p/1080p/4k (no 4k on Turbo)
- **sound**: sound effects toggle (not on Turbo); **first/last frame**: first_frame + last_frame (Turbo: first only)
- For i2v the aspect follows the first frame (≥300px, ratio 1:2.5–2.5:1)
